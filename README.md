## 📖 About The Project

**Heaven Furniture Mart** is a premium, responsive furniture and interior styling website created for a bespoke furniture brand based in **Chattogram, Bangladesh**.

The website is designed to feel more like a luxury interior studio than a traditional furniture catalogue.

The core brand message is:

> **Furniture, crafted around you.**

The experience combines:

- Luxury visual storytelling
- Bespoke furniture positioning
- Curated furniture collections
- Premium craftsmanship messaging
- Showroom discovery
- Design consultation
- Delivery and installation information
- AI-powered customer assistance
- Direct customer contact options

The primary goal is to help a visitor understand the brand quickly and naturally move from **discovery → exploration → showroom/project enquiry**.
